# FacturaBot v1.0.0

Versión inicial de FacturaBot y Fiscal API.

Incluye:

- agente y guía de configuración para Muse;
- código Google Apps Script, dashboard y plantilla de Google Sheets para la Fiscal API;
- contrato compartido de consulta y administración de perfiles fiscales;
- skills para Walmart, Farmacias Guadalajara y La Gran Bodega;
- plantilla y documentación para agregar skills;
- carpetas de referencia para Grok Bot, OpenAI Dots y buzz.xyz, pendientes de completar y validar.
