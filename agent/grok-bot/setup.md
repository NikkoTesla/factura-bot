# Setup — Grok Bot

Pendiente de documentar el proceso completo de instalación de FacturaBot en Grok Bot.

## Requisitos mínimos

- configurar el agente;
- cargar las skills necesarias;
- configurar el endpoint de Fiscal API;
- guardar la API Key en la bóveda/secret manager;
- probar una consulta fiscal;
- probar una facturación end-to-end.
